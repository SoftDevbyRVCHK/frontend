Файл index.html - симуляция движения корабля, реагирует на стрелки, wasd
Файл create_interface.html - редактор корабля, старая версия
Файл test_client.html - простейший клиент, рисует квадраты на экране, свой квадрат перемещается в место клика мышки
Файл server.py - сервер для test_client.html, работает с http запросами
Файл admin_create_module.html - это переработанный в js формат файл create_scheme.py. 
Файл create_scheme.md - инструкция к py файлу, но кардинальных отличий в js версии нет.

В папке html/data/images/floors хранятся все получившиеся у меня текстуры полов (размер плитки пола 32 на 32).

На данный момент картинки в html/data/images не отформатированы под 32 на 32 формат!!!
